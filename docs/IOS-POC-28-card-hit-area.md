# IOS-POC-28 — 點左邊影片卡的右半部，會開到右邊的影片

- 狀態：**已修正並隨 `0.1.25 (26)` 發布（Release build 編譯成功）；真機未驗證。**
- 使用者回報（2026-09-26，附首頁截圖，圈出左邊影片卡的右半部）：「點選我圈起來的位置，會播放到右邊的影片。」
- 分類：quick-fix（範圍侷限、設計已確立，依 AGENTS.md §7 免設計研究門檻）。

## 一、原因

1. `VodCard` 的海報以 `image.resizable().scaledToFill()` 填滿 2:3 的卡片（`ios/WebHTVApp/Sources/WebHTVApp.swift` `VodCard`，約 `:886-935`）。橫向海報填滿時，寬度會超出卡片。
2. 卡片用 `.clipped()` 與 `.clipShape(.rect(cornerRadius: 10))` 裁切。SwiftUI 的裁切只影響繪製，不影響觸控範圍，所以超出卡片的那一段圖雖然看不到，仍會接收點擊。
3. 格狀排列中，右邊的卡片畫在左邊卡片之上；右邊卡片的寬海報向左超出，蓋住左邊卡片的右半部，點那裡就開到右邊的影片。

## 二、修正

`VodCard` 最外層加 `.contentShape(.rect(cornerRadius: 10))`（`WebHTVApp.swift:932`），觸控範圍等於卡片本身的圓角矩形。

- 首頁格狀與搜尋結果共用 `VodCard`，兩處一起修正。
- 未修改：觀看記錄的小縮圖在 `List` 列內，列只接收自己範圍內的觸控，不受影響；詳情頁的單張海報旁沒有其他可點的卡片。
